# TÜİK 2022 reference basket

This CSV preserves 409 distinct seven-digit item codes and Turkish/English descriptions from the 2022 Madde Listesi tab of the supplied AKÇA tracking workbook.

It does not include official 2022 item weights. Historical average prices are not imported or used as the AKÇA price-index base. Verify and attach official source citations before marking any item or variant weight as verified.

See docs/METHODOLOGY.md before collecting or calculating prices.
